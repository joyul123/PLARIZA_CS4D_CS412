Adaptive Music Recommendation System
Description

The Adaptive Music Recommendation System is a Python command-line
application that provides personalized music recommendations based on
the user's listening behavior.

The system uses two IF-THEN adaptive rules to change its recommendations
depending on how frequently the user skips songs and which music genre
the user listens to repeatedly.
Required Adaptive Rules

Rule 1

If the user skips songs frequently → Then recommend shorter and
popular songs.

Reason: Frequent skipping may indicate that the user is not interested
in many of the songs being played. Recommending shorter and popular songs
can provide options that are more likely to match the user's preferences
and keep them engaged.

Rule 2

If the user listens to one genre repeatedly → Then recommend more songs
from that preferred genre.

Reason: Repeatedly listening to a specific genre indicates that the
user may enjoy that type of music. Recommending more songs from the genre
creates a more personalized listening experience.
